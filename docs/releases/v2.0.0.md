# Kit v2.0.0

Kit v2.0.0 is the conservative coding-agent-first major release.

## Notable Changes

- Adds local-only deterministic `kit context resolve` with five declarative
  workflow contracts.
- Adds bounded private local `kit usage` telemetry and explicit report, status,
  refresh, clear, enable, and disable controls.
- Keeps `kit init`, living specifications, registry-backed rules, dispatch,
  pull-request repair, health, validation, and reconciliation as first-class
  interfaces.
- Keeps `kit reconcile` behavior unchanged.
- Keeps the separate `git-wt` executable unchanged.
- Removes feature notes as an active Kit concept without deleting existing
  downstream project-owned content.
- Removes low-use and duplicative command groups listed in
  [commands.md](../commands.md).
- Preserves historical specifications as repository evidence.

## Required Migration

After installing v2, preview before applying managed updates:

```bash
kit reconcile --include-files --dry-run --diff
```

See [migration-v2.md](../migration-v2.md) for the complete procedure.

## Release And Activation

Merging the implementation PR causes the main-branch release workflow to create
`v2.0.0` when no v2 tag exists. Only after that release succeeds should the
binary be installed and the weekly health automation be updated to read overall
usage evidence. Those post-merge operations are intentionally outside the PR.
