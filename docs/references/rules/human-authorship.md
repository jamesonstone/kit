# Ruleset: human-authorship

## Purpose

- Keep displayed authorship human-only. Coding agents may do the work; they must not be named or shown as authors.
- Cover commits, pull requests, issues, comments, trailers, and any other attribution surface an agent would write.
- Pointer-load this file at authorship boundaries. Do not copy it into always-loaded instruction files.

## Applies When

Load this ruleset immediately before:

- Creating or amending a commit, including author, committer, message, and trailers
- Opening or updating a pull request or issue, including title, body, comments, and assignees
- Writing any generated-by, co-authored, signed-off, made-with, or similar credit

Do not load it for ordinary implementation or documentation edits that do not set authorship or insert credit.

## Rules

- The human user is the only git author, git committer, GitHub author, and displayed credit.
- Assign issues and pull requests to the human user. Do not assign a coding agent, assistant, bot, or tool.
- Never set a coding agent, assistant, bot, tool, or autogenerated identity as author or committer.
- Never pass `--author`, `GIT_AUTHOR_*`, or `GIT_COMMITTER_*` values that resolve to a non-human identity.
- Never insert agent or tool attribution, including `Co-authored-by:`, `Generated-by:`, `on-behalf-of:`, "Generated with …", "Made with …", or equivalent footers, badges, file headers, or comments naming the agent or tool. Do not add `Signed-off-by:` for an agent or tool; a human DCO trailer for the user is allowed.
- If human identity cannot be confirmed, stop and ask. Do not fall back to an agent identity.

## Anti-Patterns

- Inlining this ruleset into `AGENTS.md`, `CLAUDE.md`, Copilot instructions, or prompt bodies.
- Loading this file during unrelated coding work that does not write authorship or credit.
- Leaving plugin-default agent trailers, PR footers, or co-author metadata in place.
- Attributing an agent "for transparency" or "because it wrote the diff."

## Verification

Before commit, push, or pull-request creation, confirm:

- `git var GIT_AUTHOR_IDENT` and `git var GIT_COMMITTER_IDENT` are the human user.
- The commit message, PR body, issue body, and comments contain no agent or tool attribution.
- GitHub shows the human user as issue assignee, PR assignee, and commit author.
- The staged diff has no generated-with credits, agent badges, or author headers.

## Examples

Allowed:

```text
docs(GH-166): :memo: require human-only authorship

Original ask: add a Kit rule so only the human user is attributed.
```

Forbidden:

```text
Co-authored-by: Cursor <cursoragent@cursor.com>
Generated with Claude Code
Made with GitHub Copilot
```
